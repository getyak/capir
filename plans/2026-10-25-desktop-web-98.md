# Desktop and Web continuity and recovery

## Outcome

Preserve user input and truthful state through navigation, authentication
recovery and ordinary workspace interactions. Keep authored names, excerpts,
objectives and errors intact while localizing product-owned interface text.
A complete experience assessment still requires observed Web and installed
macOS behavior; builds, signing and partial tests do not establish that outcome.

## Changes

- Carry the active language through login, People, search, Today and protected
  workspace recovery. Preserve date instants, source zones and all-day end rules.
- Retain bounded composer presentation across navigation without storing raw
  draft text in the presentation cache; keep composition and account fences.
- Confirm actual local Auth.js cookie removal before clearing local intentions.
  A rejected or ambiguous sign-out preserves drafts. Confirmed completion hides
  private content and its directory cache before cleanup or navigation, and
  retains a manual fixed GET recovery without replaying the action.
- Preserve prerequisites and undecided conditional choices in conversation
  prompts. Respect explicit response length and avoid unsolicited retention
  explanations while keeping the prohibition on false retention guarantees.
- Localize native-owned login, device-settings and companion chrome in five
  resource tables. Connect the companion virtual accessibility button's default
  press to its existing workspace opener; leave mouse/drag and capture behavior.

## Validation and remaining work

Focused local checks passed 316 Web cases, 31 additional sidebar cases and 59
prompt-delivery cases, plus Web typechecking and documentation checks. Actual
Auth.js cookie production and rendered private-content fencing are covered,
including failed navigation and stale binding generations. These tests do not
replace live Next transport, installed native interception or model semantics.

Native resources have matching key and placeholder sets, and syntax checks
passed. Native compilation, XCTest and hosted accessibility execution await the
existing disposable macOS workflow. Its test host starts the application, so a
fixture preference suite alone does not isolate a real user profile.

The latest sign-out, conversation-prompt and native changes require deployment
and repeat observation before completion. Retain original failing samples in
purpose-bound delivery evidence. Use named synthetic test conversations and
verify their cleanup. Private operational receipts are retained separately.

## Assessment scope

Observe recovery and truthful state, keyboard and input, reading hierarchy,
visual consistency, lifecycle and accessibility on Web and macOS separately.
Cover offline/expiry, stale replies, send/stop/queue/withdraw/resume, navigation,
IME and attachments, People/Today/Time/settings, light/dark/narrow presentation,
reload and native relaunch. Unknown criteria stay unscored. Native nested
producer/search/error text is outside the three-view localization slice and
still requires its own observation; do not claim complete native localization.
