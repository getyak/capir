# Source map

Checked 2026-08-04. Recheck platform guidance when deployment targets change.

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines) — current platform guidance.
- [Apple design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles) — hierarchy, harmony, and consistency.
- [Apple accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) — accessible interface principles and platform behavior.
- [Apple feedback](https://developer.apple.com/design/human-interface-guidelines/feedback) — communicate action and system status.
- [Apple modality](https://developer.apple.com/design/human-interface-guidelines/modality) — use focused interruption proportionately.
- [Apple privacy](https://developer.apple.com/design/human-interface-guidelines/privacy/) — clear purpose and user control around protected resources.
- [Apple machine learning](https://developer.apple.com/design/human-interface-guidelines/machine-learning) — explain capability and preserve control for ML-driven features.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — cross-platform accessibility success criteria.
- [WCAG 2.2 Understanding Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) — minimum target-size criterion and exceptions for web content.

Apple's platform conventions and WCAG are baselines, not substitutes for assistive-technology and actual-user testing.
